# 🚀 Быстрое исправление БЕЗ Node.js

## Проблема:
Android приложение не может подключиться к backend, потому что использует `localhost` вместо `10.0.2.2`

## ✅ Решение (БЕЗ Node.js):

### **Шаг 1: Запустите Backend правильно**

1. Откройте PowerShell
2. Выполните команды:

```powershell
cd C:\Users\Winter\Desktop\student-performance-prediction\printshop-crm\backend

# Активируйте виртуальное окружение
venv\Scripts\activate

# ВАЖНО: Запустите с --host 0.0.0.0
uvicorn main:app --host 0.0.0.0 --reload
```

**Почему это важно?**
- `--host 0.0.0.0` позволяет backend принимать подключения не только с localhost
- Без этого эмулятор не сможет подключиться к backend

### **Шаг 2: Пересоберите приложение в Android Studio**

Я уже обновил код (`api.js`), теперь нужно пересобрать:

1. **Откройте Android Studio**

2. **В меню выберите:**
   - `Build` → `Clean Project`
   - Дождитесь завершения

3. **Затем:**
   - `Build` → `Rebuild Project`
   - Дождитесь завершения (может занять 1-2 минуты)

4. **Запустите приложение:**
   - Нажмите зеленую кнопку **Run** (или Shift+F10)
   - Выберите эмулятор
   - Дождитесь запуска

### **Шаг 3: Проверьте подключение**

1. **Убедитесь, что backend работает:**
   - Откройте браузер на компьютере
   - Перейдите: `http://localhost:8000/docs`
   - Должна открыться Swagger документация

2. **В приложении попробуйте зарегистрироваться:**
   - ФИО: `Тест Пользователь`
   - Email: `newuser@test.com` (используйте НОВЫЙ email!)
   - Пароль: `test123`
   - Подтверждение: `test123`

## ❓ Если все равно не работает:

### **Проверка 1: Backend запущен правильно?**

В PowerShell где запущен backend должно быть:
```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

Если видите `http://127.0.0.1:8000` - значит запущен неправильно!

### **Проверка 2: Используете новый email?**

Ошибка "Email already exists" означает, что этот email уже есть в базе.

**Решение:** Используйте другой email или очистите базу данных:

```powershell
cd C:\Users\Winter\Desktop\student-performance-prediction\printshop-crm\backend

# Остановите backend (Ctrl+C)

# Удалите базу данных
Remove-Item printshop.db

# Пересоздайте базу
alembic upgrade head

# Запустите backend снова
uvicorn main:app --host 0.0.0.0 --reload
```

### **Проверка 3: Приложение пересобрано?**

После изменения `api.js` обязательно нужно:
1. `Build` → `Clean Project`
2. `Build` → `Rebuild Project`
3. Заново запустить приложение

---

## 🔍 Как проверить, что изменения применились:

После пересборки в Android Studio:

1. Откройте **Logcat** (внизу Android Studio)
2. Запустите приложение
3. В логах найдите строку с URL (может быть при ошибке подключения)
4. Должно быть `10.0.2.2:8000`, а не `localhost:8000`

## 📝 Что было изменено в коде:

Файл `frontend/src/services/api.js` теперь автоматически определяет:

- **Android эмулятор:** `http://10.0.2.2:8000`
- **iOS симулятор:** `http://localhost:8000`
- **Веб-браузер:** `http://localhost:8000`

`10.0.2.2` - это специальный IP адрес для доступа к компьютеру из Android эмулятора.
